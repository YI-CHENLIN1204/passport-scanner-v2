# Project Context

## 背景

舊版 Passport Scanner 使用付費雲端 AI。V2 改採瀏覽器端 OCR，主要目的有兩個：

1. 降低長期 OCR / AI API 成本。
2. 降低把旅客敏感證件影像送往外部辨識服務所造成的資安與隱私疑慮。

V2 是旅行社內部工具，不是旅客自助系統。使用者預期是少數內部人員，因此現階段不投入複雜帳號與權限管理。

## 主要使用流程

1. 內部人員建立或選擇團別／產品。
2. 設定出發日、回國日、截單日與需收集的證件類型。
3. 上傳旅客證件照片。
4. 瀏覽器端執行 OCR。
5. 顯示 OCR 結果與原圖供人工逐筆核對。
6. 人工修正錯誤欄位並確認。
7. 需要時建立／更新旅客主檔與證件版本。
8. 人工按鈕觸發匯出 Google Sheets。

## 團別與證件方向

預期至少包含：

- 國旅：身分證或護照擇一。
- 出境：護照。
- 大陸團：護照 + 台胞證。
- 入境：保留未來擴充空間，但 V2 先以目前內部實際需求為主。

## V2 與未來版本

### V2

- 內部使用。
- 瀏覽器端 OCR。
- 人工覆核。
- Google Sheets 手動匯出。
- 不直接進 ERP。

### V3（未來構想）

- 可考慮租用常駐伺服器。
- 可考慮旅客自行上傳。
- 可依需求支援即時或批次處理。

### V4（未來構想）

- 將「新增／更新主檔、建立版本、匯出」等操作進一步整合成更少的按鈕與更自動化的流程。

V3 / V4 均不是目前 V2 的實作範圍。
